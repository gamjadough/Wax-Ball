# 모바일 화면 높이 보정 (2026-10-13)

가로 높이가 240px까지 줄면 로비 시작 버튼이 화면 밖으로 밀리는 문제를 재현했다. 기존 모바일 검사의 최소 높이는 320px였다.

`VisualViewport.height`와 `innerHeight` 중 실제로 보이는 높이로 게임을 맞춘다. 주소창의 크기 변경과 회전 이벤트에서 다시 계산한다. 모바일 문서 스크롤을 막되, 주요 조작 요소가 보이는지 별도로 검사한다. 높이 280px 이하에서는 제목·설명·장식을 줄이고, 전투의 상단 로고를 생략하며, 결과 버튼을 나란히 배치한다. 안내 문구는 화면 아래 알림으로 표시해 화면을 밀어내지 않는다. 조작 버튼은 44px 이상을 유지한다.

검증 범위를 568×240, 667×260, 844×280부터 기존 가로·태블릿 화면까지 12종으로 확대했다. 레이아웃 높이 390px와 실제 표시 높이 240px가 다른 상황, 안전 영역 여백, 주소창이 사라졌을 때의 복귀도 검사한다. 세로 회전 중단·복귀와 터치 입력 검사는 유지한다. 결과 화면은 568×240에서 버튼 위치를 확인한다.

## 말풍선·대사 보정

이전의 낮은 화면 스타일이 전투 말풍선을 숨기고 있었다. 해당 숨김 규칙을 제거하고 240px부터 모든 검사 크기에서 대사를 표시한다. 로비·전투 말풍선은 모바일에서 회전을 없애고 둥근 사각형과 일정한 꼬리로 표현한다. 글자는 최소 11px로 표시하고 영역 안에서 줄바꿈하며, 공은 말풍선을 배치하고 남은 무대 높이에 맞춰 조정한다. CSS 컨테이너 단위를 지원하지 않는 경우에는 높이 비율을 사용한다.

모바일 검사에서 로비 말풍선과 꼬리의 패널 내 위치, 실제 문자 영역, 양쪽 공의 5단계 대사 변경, 44px 공 터치 영역, 세로 회전·복귀와 안전 영역을 함께 확인한다.
