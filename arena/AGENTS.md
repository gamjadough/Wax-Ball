# 프로젝트 작업 지침

- 사용자는 2026-10-12에 앞으로의 작업을 Git으로 커밋하고 GitHub의 새로운 경로로 배포하도록 요청했다.
- 작업 완료 후 변경에 적합한 검증을 실행하고 관련 변경을 Git 커밋으로 남긴다.
- 배포 대상은 `https://github.com/gamjadough/Wax-Ball.git`의 `main` 브랜치 내 `arena/` 디렉터리다. 공개 URL은 `https://gamjadough.github.io/Wax-Ball/arena/`다.
- `deploy.ps1`로 커밋된 프로젝트를 기존 원격 main 위에 추가하고 푸시한다. 실제 공개 URL의 응답과 게임 동작을 확인한다.
- 커밋, 푸시, 배포 결과와 배포 URL을 사용자에게 전달한다. 실패하거나 대기 중이면 완료했다고 보고하지 않는다.
- 비밀 정보, 의존성 폴더, 테스트 생성 산출물은 커밋하지 않는다.
