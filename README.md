# Wax-Ball

작은 공 하나로 시작하는 즐거움. **Wax-Ball(왁스볼)**은 볼을 누르고 깨뜨리며 골드를 모으는 브라우저 게임 프로젝트입니다.

**[왁스볼 사이트](https://gamjadough.github.io/Wax-Ball/)** · **[왁뿌볼 바로 플레이](https://gamjadough.github.io/Wax-Ball/wakppuball/)**

## 게임 소개

왁뿌볼을 클릭하거나 터치하면 공에 금이 생기고, 소리와 함께 눌리는 모습을 볼 수 있습니다. 공을 끝까지 깨뜨리면 골드를 얻고 새로운 공이 나타납니다.

모은 골드로 다음 볼을 순서대로 해금하고, 도감에서 해금한 볼을 골라 플레이할 수 있습니다.

## 플레이 방법

1. 사이트에서 **왁뿌볼 시작하기**를 누릅니다.
2. 화면 중앙의 볼을 클릭하거나 터치해 깨뜨립니다.
3. 획득한 골드로 새로운 볼을 해금합니다.
4. **도감**에서 볼을 살펴보고 사용할 볼을 선택합니다.

## 진행 저장과 환생

골드, 해금한 볼, 선택한 볼, 환생 횟수는 현재 기기의 브라우저에 자동 저장됩니다. 환생은 500,000G부터 시작하며, 환생할 때마다 Gold와 도감은 초기화되고 파괴 보상 배율은 2배가 됩니다. 깨는 중인 볼은 다시 온전한 상태로 시작합니다.

다른 기기·브라우저·프로필에서는 별도의 진행 상황으로 시작합니다. 사이트 데이터를 삭제하면 저장 기록도 삭제되며, 시크릿 모드에서는 일반적으로 창을 닫으면 기록이 사라집니다.

## 온라인 랭킹·관리자 서버 연동

정적 GitHub Pages 배포만으로는 Gold·환생 검증과 공용 랭킹을 안전하게 제공할 수 없습니다. 게임 화면은 `GET /api/rankings`를 호출할 준비가 되어 있으며, 서버 연결 전에는 안내만 표시합니다.

실서비스 API는 인증된 사용자 기준으로 다음을 서버에서 처리해야 합니다.

- `POST /api/game/hit`: 선택한 볼의 파괴, 보상, Gold를 서버에서 검증·반영
- `POST /api/game/unlock`: 해금 비용과 순서를 서버에서 검증
- `POST /api/game/rebirth`: 요구 Gold, 초기화, 환생 배율을 서버에서 검증
- `GET /api/rankings`: `rebirths DESC, gold DESC`로 닉네임·환생 횟수·현재 Gold 반환
- `/api/admin/*`: 서버 세션의 관리자 권한을 검사한 뒤 Gold 지급/회수, 강제 해금, 환생·파괴·균열·사운드·화면 효과 테스트, 공지 및 향후 이벤트의 시작·종료·카운트다운을 처리

관리자 여부와 모든 중요한 게임 수치는 클라이언트가 아니라 서버·데이터베이스에서만 판정해야 합니다. 관리자 UI도 `/api/me` 같은 서버 권한 확인 결과가 관리자일 때만 렌더링하세요.

## 프로젝트 구성

- `index.html`: Wax-Ball 랜딩 페이지
- `wakppuball/index.html`: 왁뿌볼 게임 화면
- `wakppuball/style.css`: 게임 스타일
- `wakppuball/js/`: 볼 데이터, 그림, 사운드 및 게임 로직

HTML, CSS, JavaScript로 구성되어 있으며 별도 프레임워크 없이 브라우저에서 실행됩니다.
