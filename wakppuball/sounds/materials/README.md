# Material foley

Original audio dedicated to CC0-1.0. No third-party recordings.

Each ball has early/mid/late/final stages: immediate wax shell transients, progressively denser fractures and a stronger collapse with short fragments. Fruit/water add fluid texture; gems add brief nonharmonic chips; space/transcendent balls add restrained pressure, air and body layers. These are synthesized foley, not live recordings.

22,050 Hz, 16-bit mono. Peaks 0.46 / 0.49 / 0.52 / 0.59; final tail under 1.05 s. Generated deterministically by `tools/build-material-sounds.py` (NumPy). Only the selected ball is preloaded; audio cache is bounded. Existing yellow/event/seasonal/gem/skin audio is unchanged.
