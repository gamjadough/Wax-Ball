# 초보자 흐름 로컬 미리보기

- 첫 파괴 → 초록 볼 해금 → 100G 망치 구매를 현재 목표로 안내한다.
- 균열 진행·남은 균열 수·기본 파괴 보상과 다음 볼의 해금 효과를 표시한다.
- 상점에서는 망치를 먼저 표시한다. 초보자에게 후반 뽑기 설명을 먼저 보여주되, 원하면 기존 뽑기를 살펴볼 수 있다.
- Gold가 부족해도 환생 설명은 열 수 있다. 실제 환생의 비용 검증은 기존대로 유지한다.
- 게임 방법에서 닉네임 빠른 시작·서버 저장·이메일 연결의 차이를 안내한다.
- 가격·보상·클릭 요구량·계정/저장 구조는 변경하지 않는다. 행성 이상 해금·환생·관리자·테스트 모드에는 초반 목표 안내를 표시하지 않는다.

`WAKPPU_LOCAL_BEGINNER_PREVIEW=1 WAKPPU_LOCAL_PORT=4181 node tools/local-server.mjs`

위 옵션은 로컬 샘플 일반 계정의 시작 Gold만 0으로 설정한다. 운영 데이터와 연결되지 않으며 다른 미리보기에는 영향을 주지 않는다.
브라우저별 로컬 진행과 빠른 시작 샘플 계정의 서버 메모리 진행은 운영 계정과 구분한다.

검증: `tools/beginner-browser.py` (모바일 세로 320/390, 가로 844, PC 1200; 0G 실플레이 → 해금 → 망치 → 재실행 유지).
`WAKPPU_BEGINNER_LAYOUT_ONLY=1`은 이미 검증한 긴 성장 루프를 제외하고 레이아웃·안내만 재검증한다.

사용자 확인 전에는 개발 브랜치만 푸시하며 운영 main으로 배포하지 않는다.
