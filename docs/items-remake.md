# 뽑기 아이템 리메이크

- 상점 꿀 ×2와 보석 코팅 ×3은 뽑기의 Gold 배율과 곱연산한다.
- 뽑기는 Gold / 파괴 모션 / 재등장 대기 세 계열 각각 최강 효과 하나만 적용한다.
- 왁뿌볼의 심장: 30분간 Gold ×3, 파괴 모션 속도 ×2, 재등장 속도 ×3.
- 심장보다 강한 Gold ×4 아이템이 있으면 Gold만 ×4로 대체하고 심장의 나머지 두 효과는 유지한다.
- 기존 균열·타격·난이도 아이템은 재등장 대기 단축으로 변경한다. 망치의 균열량에는 영향을 주지 않는다.
- 재생 조각 / 작은 재생의 종 / 재생 실 / 재생 촉진제 / 재생의 종 / 탄생 결정 / 시간 가속 왁스 / 생명의 왁스 / 재생의 핵 등의 이름으로 변경한다.
- 재등장 속도 ×2는 파괴 연출이 끝난 뒤 대기 1초를 0.5초로, ×3은 약 0.333초로 줄인다. 파괴 모션 자체는 깃털 계열로만 가속한다.
- 파괴 연출이 끝나기 전에 다음 볼을 만들지 않는다. 마지막 균열 표시도 유지한다.
- 아이템 ID, 보유 수량, 남은 횟수/시간, 뽑기 가격/확률/천장과 기존 진행도를 유지한다. 횟수형은 실제 적용된 파괴에서만 차감한다.

서버: `20261019_items_remake.sql`은 기존 API 권한과 래퍼를 유지하며 카탈로그 및 내부 효과 계산만 변경한다. 기존 인벤토리를 초기화하지 않으며 반복 적용 가능하다.
