# 로컬 모의 결제

실제 결제사 API, 카드·계좌 입력, 운영 계정·DB를 사용하지 않는 체험입니다.
토스페이먼츠 테스트 결제와도 구분됩니다. 아래 성공 버튼은 로컬 서버의 가상 승인입니다.

## 상품

- 응원팩: 예시 1,100원. 후원자 칭호와 계정·랭킹 닉네임 테두리.
- 별빛 오라 스킨: 예시 3,300원. 모든 볼에 별빛 고리와 반짝임을 적용하고 장착·해제 가능.
- 상품은 외형 전용이며 Gold·공격력·클릭 수·랭킹 점수·기존 스킨 뽑기에 영향을 주지 않습니다.
- 각 상품은 계정당 하나 보유합니다. 모의 환불 후에는 다시 구매할 수 있습니다.

## 실행 (저장소 루트의 PowerShell)

```powershell
$env:WAKPPU_LOCAL_PAYMENTS='1'
$env:WAKPPU_LOCAL_PORT='4195'
node tools/local-server.mjs
```

`http://127.0.0.1:4195/?preview=payments` 접속. 빠른 시작 샘플 계정이 자동 연결됩니다.
`로컬에서 이메일 연결 완료 가정`으로 구매 가능 상태를 체험할 수 있습니다.
실제 이메일을 인증하거나 운영 계정에 연결하는 동작은 아닙니다.
서버를 재시작하면 가상 주문·지급 상태가 모두 초기화됩니다. 이 경우 `로컬 샘플 다시 연결`을 누르세요.

## 확인 순서

1. 이메일 연결 전 구매 차단 → 연결 완료 가정 → 상품 선택.
2. 별도 모의 결제 화면에서 성공·취소·실패 선택 → 상점 복귀 및 구매 내역 확인.
3. `승인 후 지급 누락 가정` → 상점에서 새로고침 → 구매 내역의 `미지급 상품 다시 지급`.
4. 스킨 장착 → 상점 닫기 → 볼의 별빛 오라 확인 → 새로고침 후 장착 유지.
5. 구매 내역에서 모의 환불 → 상품 회수와 스킨 해제 확인.

성공은 주문 승인과 상품 지급을 분리합니다. 서버 가격과 소유 계정을 검증하고, 중복 주문·지급을 막습니다.
결제하지 않은 주문은 30분 후 만료되며, 이미 승인된 주문은 이후에도 지급을 복구할 수 있습니다.

## 운영과의 분리 / 다음 단계

`WAKPPU_LOCAL_PAYMENTS=1`이 없으면 모의 API·결제 페이지는 404를 반환합니다.
일반 페이지와 운영 HTML에는 상점 스크립트가 주입되지 않습니다.
운영 DB·결제사 키·웹훅·실제 환불·관리자 정산은 이번 로컬 체험 범위에 포함되지 않습니다.
실제 PG 테스트로 넘어갈 때는 서버 DB 주문·지급 기록, 검증된 결제 승인·웹훅·재조정 작업,
관리자 주문 조회·환불 정책, 비밀 키 관리가 필요합니다. 모의 승인 API를 운영 결제 승인에 재사용하면 안 됩니다.

```powershell
node --test tools/payment-demo.test.mjs tools/payment-demo-http.test.mjs tools/guest-account.test.mjs
python tools/payment-demo-browser.py <node.exe 경로>
```

브라우저 테스트는 Python Playwright와 Edge가 필요하며 `WAKPPU_TEST_PYTHON_PATH`에 설치 위치를 지정할 수 있습니다.
