# 친구 서버 입장

친구 서버는 입장 암호를 서버에서 검증하며 공개 서버는 입장 제한이 없다.
암호와 해시는 소스에 포함하지 않는다. 신규 기기는 암호를 한 번 확인한다.

- 현재 로그인한 계정에 서버 플레이 기록이 있으면 암호를 생략한다. 기존 이메일 계정은 입장 화면의 기존 계정 로그인으로 들어갈 수 있다.
- 서버가 발급한 무작위 입장 토큰만 기기의 localStorage에 저장한다. 재방문과 새 탭에도 사용할 수 있고, 검증 시 365일 만료를 갱신한다. 저장소를 지운 기기는 기존 계정 로그인 또는 암호 확인이 필요하다.
- 예전 sessionStorage 토큰도 다음 방문 때 localStorage로 이전한다.
- 클라이언트의 닉네임, 계정 메타데이터, 골드 저장 파일만으로 서버의 입장 권한을 부여하지 않는다.
- 밴·점검·관리자 권한은 기존 게임 API에서 별도로 검사한다.
- 친구 서버의 유료 상점은 이용 중단 상태다. 신규 주문·입금 알림·판매 재개는 서버에서 차단하며, 기존 보유 상품·주문 이력과 관리자의 기존 주문 처리는 보존한다.

검증: 친구 서버 SQL 테스트, 공개 서버 12월 경계 테스트, `tools/returning-public-browser.py`의 320×640·844×390·390×844·1200×900 마우스/터치 및 화면 크기 전환. 실물 휴대폰 검증은 수행하지 않았다.
