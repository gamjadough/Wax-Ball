# 관리자 구매 알림

비익명 관리자 로그인 중 화면이 보이는 동안 15초 간격으로 새 주문과 구매자의 입금 알림을 확인한다. 오른쪽 아래 작은 알림에서 닉네임·상품·금액·전체 확인 대기 수를 보여주고, 주문 확인을 누르면 해당 미처리 주문만 관리자 목록에 연다. 이미 처리·취소된 경우 안내하며 전체 주문 보기로 돌아갈 수 있다. 알림은 실제 입금 확인이나 자동 지급을 의미하지 않는다.

닫은 주문/상태 알림은 계정별 sessionStorage에 최대 500건을 기억해 같은 탭 새로고침 시 반복하지 않는다. pending→claimed 변경은 별도 알림이다. 새 탭·새 브라우저 세션은 현재 미처리 주문을 다시 안내할 수 있다. 관리자 직접 지급, 승인·취소·환불·회수된 주문은 제외한다. 계정 변경·관리자 권한 상실 시 알림을 숨기고 오래된 응답은 폐기한다. 알림음·브라우저 외부 알림은 없다.

`admin_purchase_inbox`는 서버에서 실제 Auth 사용자와 관리자 역할을 검증하고 기존 점검·정지 검사를 재사용한다. 요약 응답은 최근 변경 20건과 전체 대기 건수를 반환한다. 계좌·입금자 정보는 특정 주문을 여는 요청에서만 반환한다. 부분 인덱스로 미처리 계좌이체 주문만 조회하며 새 테이블·Realtime 구독은 없다. 알림 조회는 관리자 입금 확인 양식을 다시 그리지 않아 입력 중인 거래 식별 기록을 보존한다.

배포: `20261022091944_admin_purchase_inbox.sql` 적용 → `tools/purchase-notices-production-check.sql` 롤백 검증 → 정적 파일 배포.

검증: `node --test tools/purchase-notices.test.mjs`, `python tools/purchase-notices-browser.py`. 로컬 은행 preview에 `WAKPPU_LOCAL_PURCHASE_NOTICES=1`을 추가하면 테스트할 수 있다. 브라우저 검증은 두 계정과 320×640, 844×390 터치 에뮬레이션을 사용하며 실제 입금·실물 기기 검증은 아니다.
