# 월간 수동 클릭 랭킹

한국 시간 매월 1일 00시부터 다음 달 1일 전까지 서버가 정상 처리한 수동 공격을 1점씩 누적한다. 망치 피해량과 관계없이 일반·이벤트·한정 공과 푸른젬 볼을 모두 집계한다. 불씨의 서버 검증 자동 공격은 제외한다. 2026년 10월은 배포 후부터 시험 집계하며 보상은 없고, 11월부터 정식 시즌이다. 과거 클릭을 추측해 소급하지 않는다.

랭킹 → 월간 클릭에서 집계 월, 상위 100명, 내 순위·정확한 클릭 수, 종료 시각까지 남은 시간, 규칙을 볼 수 있다. 전체 랭킹·월간 탭 간 늦은 응답을 분리한다. 점검·야간에도 기존 랭킹 읽기 권한으로 조회한다. 관리자, 랭킹 숨김, 제재 중, 정리 대상 게스트는 제외한다. 동점은 해당 점수에 먼저 도달한 시간, UUID 순으로 정한다.

## 월말 영구 보상

| 조건 | 보상 |
|---|---|
| 1위 | 월이 새겨진 클릭왕 카드 + 클릭왕 칭호 |
| 2위 | 해당 월 은빛 도전자 카드 |
| 3위 | 해당 월 동빛 도전자 카드 |
| 1~10위 | 해당 월 클릭 TOP 10 칭호 |
| 1,000클릭 이상 | 해당 월 참여 배지 |

보상은 중복 조건을 모두 지급한다. 인벤토리 → 프로필에서 카드·칭호·참여 배지를 각각 장착/해제한다. 자동 장착하지 않는다. 영구 보관하며 골드·공격력 등 능력치에는 영향을 주지 않는다. 월간 카드에는 관리자 무료 이용 우회가 없다. 기존 1위 달성 카드, 현재 1위 칭호, 후원자·프리미엄 권한은 그대로 유지한다.

## 서버 처리

- 기존 입력 제한 함수의 성공 처리 경로에 집계한다. 기존 게임 행 잠금, 요청 재전송 확인과 실제 공격 성공 이후에 같은 트랜잭션으로 기록한다. 거절·재시도·진행도 저장으로 점수를 추가하지 않는다. 일반 요청의 자동 공격 출처 위장은 기존 불씨 래퍼가 제거한다.
- 플레이어별 월간 행을 갱신하며 모든 클릭의 새 로그를 만들지 않는다. 월·점수·도달 시각·UUID 순서 인덱스와 사용자별 조회 인덱스를 둔다.
- 시즌 공유 잠금은 동시 공격을 허용하고, 월말 확정은 시즌 단독 잠금으로 한 번만 실행한다. 확정 결과와 보상 지급이 한 트랜잭션이므로 중간 실패 시 함께 롤백한다.
- `wakppu-monthly-settle` pg_cron 작업이 1분마다 종료된 시즌을 확정한다. 월간 조회도 누락된 확정을 재실행한다. 사용자 호출로 정산 월이나 시간을 지정할 수 없다. 지급까지 최대 약 1분 걸릴 수 있다.
- 확정 시 참가 자격을 검사하고 순위·점수·당시 닉네임을 고정한다. 이후 공개 제외된 계정은 과거 목록에서도 숨기되 다른 사람의 확정 순위를 바꾸지 않는다. 닉네임 변경 후에도 현재 닉네임으로 프로필을 연다.
- 점수·보상·확정·선택 테이블은 RLS 및 직접 접근 차단, 내부 함수는 EXECUTE 회수. 공개 API는 본인 배지/칭호/카드 보유 여부를 서버에서 검증하고 개인 접속 기록·이메일·UUID를 공개하지 않는다.

## 검증

`tools/monthly-rankings.test.mjs`: 실제 공격/입력 제한/불씨/보석/프로필 SQL을 PGlite에 설치해 정상/고급 망치, 이벤트/한정, 중복/실패, KST 월 경계, 시험 시즌, 동점, 숨김/제재/관리자 제외, 각 보상 조건, 재정산, 영구 장착, 위조 거절, 접근 권한, 점검/야간 읽기를 검사한다. pg_cron만 로컬 모의 함수이며 운영에서는 실제 작업과 실행 기록을 따로 확인한다.

`tools/monthly-rankings-browser.py`: 터치 브라우저 320×640, 844×390, 390×844(모션 감소), 1200×900에서 실제 수동 탭 집계, 전체/월간 전환, 월 선택, 확정 보상 장착, 프로필, 빈 결과/실패/재시도, 화면 넘침을 검사한다. 실물 기기 검사는 아니다. 로컬 시드/시간 제어는 명시적으로 켠 루프백 테스트 경로에만 존재한다.

`tools/monthly-production-check.sql`: 운영 DB의 실제 수동/불씨 공격, 중복 복구, 월간 집계, 점검 중 조회와 크론/권한을 가상 계정으로 검사하고 테스트 변경은 전부 롤백한다.
