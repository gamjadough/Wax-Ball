# 할로윈 상점 탭

사탕 버튼으로 여는 할로윈 상점의 상단에 **펫 / 스킨** 탭을 배치했다.
펫 탭은 펫 상자와 펫 장착·인벤토리 교환 이동을, 스킨 탭은 잭오랜턴 스킨과 점프스케어 해제권을 보여준다.
한 번에 한 패널만 표시하며 인벤토리의 기존 펫·스킨 영역은 유지한다.

탭은 스크롤 중에도 상단에 남는다. 종류를 바꾸면 내용의 시작으로 돌아가며, 닫았다 다시 열면 마지막 선택을 유지한다.
좌우 화살표·Home·End 키로 이동할 수 있고 선택 상태와 패널 관계를 ARIA로 알린다. 터치 버튼은 최소 44px이다.

표시 위치만 변경했다. 기존 구매 가격, 사탕 차감, 중복 보상, 소유권, 확률, 효과, 시즌 종료 처리와 서버 검사는 그대로 사용한다.
서버나 데이터베이스 마이그레이션은 필요하지 않다.

검증: `tools/candy-shop-entry-browser.py`에서 PC와 터치 에뮬레이션 320×640 / 844×390 / 390×844의 표시 분리, 키보드 이동, 고정 탭, 스크롤, 재열기, 포커스 복귀, 사탕 차감, 인벤토리 교환 및 시즌 종료를 확인한다.
`tools/halloween-shop-browser.py`는 스킨 교환·장착, 음소거, 기본/월식 깜짝 연출, 영구 해제권, reduced motion과 재접속 유지를 확인한다. 실물 휴대폰 검증은 아니다.
