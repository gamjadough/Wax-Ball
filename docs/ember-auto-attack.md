# 잭오랜턴의 불씨 자동 공격

기존 파괴 연출 10% 단축을 현재 망치를 사용하는 자동 공격으로 교체한다. 기존 보유자도 별도 구매 없이 장착하면 적용된다. 꼬마 유령과 박쥐의 특성은 유지한다.

- 공격 응답 이후 1초 간격으로 시도한다. 파괴 연출, 재생성, 수동 공격 처리 중에는 기다린다. 지연된 공격을 몰아서 실행하지 않는다.
- 화면이 보이고 포커스가 있을 때 동작하며 메뉴, 숨김, 포커스 상실, 페이지 이탈 때 멈춘다. 오프라인 보상은 없다.
- 게임 화면의 44px 이상 버튼으로 일시정지/재개한다. 같은 계정의 토큰 갱신은 일시정지를 해제하지 않는다. 새로고침과 계정 전환은 기본 활성 상태로 시작한다.
- 수동 공격을 함께 사용할 수 있다. 망치 피해, 소모품 소비, 골드, 이벤트, 파란 보석과 자동 환생은 기존 공격 경로를 사용한다.
- 서버는 실제 펫 이용 권한, 장착, 공통 1초 제한, 기존 계정/점검/야간/차단 조건을 검증한다. 화면 표시 여부는 클라이언트에서 제어한다.
- 같은 요청의 재전송은 저장된 결과를 돌려주며 보상을 중복 지급하지 않는다. 사용자별 최근 64개 요청만 보관하고 클라이언트 직접 접근을 막는다.
- 검증한 자동 공격만 매크로 판정용 수동 클릭 기록에서 제외한다. 일반 요청의 출처 위장은 제거하고 기존 호출 속도 제한은 유지한다.

검증: Node 서비스·실제 SQL·스케줄러 회귀 테스트, 터치 브라우저 320×640/844×390/390×844/1200×900, 모션 감소, 네트워크 응답 유실 재시도, 운영 DB에서 가상 계정 트랜잭션 롤백 검사. 브라우저의 숨김/포커스 상태는 헤드리스 환경 제약으로 명시적으로 재현하며 실물 기기 검사는 아니다.
