# 왁뿌볼의 심장 상향

- Gold ×3 → ×6
- 파괴 모션 속도 ×2 → ×2.5
- 재등장 속도 ×3 → ×4 (파괴 연출 후 대기 약 0.333초 → 0.25초)
- 지속시간 30분 유지

기존 보유·활성 심장에도 적용한다. 수량, 만료 시각, 사용 횟수, 천장, 뽑기 가격/확률 및 다른 아이템은 변경하지 않는다. 같은 뽑기 계열 최강 효과 하나만 적용하며, 상점 꿀 ×2·보석 코팅 ×3과는 곱연산하여 ×36이 된다. 환생·이벤트 배율은 별도다.

배포: 공식 Supabase CLI로 생성한 `20261015074409_wax_heart_balance.sql`을 **기존 `20261019_items_remake.sql` 적용 후** 실행한다. 기존 배포 파일의 날짜 표기 때문에 파일 이름 순서대로 일괄 실행하지 않는다. 새 패치는 심장 정의 한 행과 기존 내부 효과 선정 함수의 심장 수치만 변경하고 API 래퍼·권한·사용자 데이터를 보존한다. 중복 실행 가능하다.

`node tools/sync-items-data.mjs --check`는 현재 클라이언트 수치와 새 심장 전용 패치의 일치를 검증한다. 과거에 배포한 마이그레이션을 덮어쓰지 않는다.
