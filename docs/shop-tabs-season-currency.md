# 상점 통합 및 할로윈 재화 자리

- 메인 뽑기 버튼 삭제. 상점 안에서 아이템 구매 / 뽑기 탭으로 전환한다.
- 기존 구매·업그레이드, 1/3/5회 뽑기, 확률·천장 및 진행 중 공개 연출을 유지한다.
- 인벤토리는 별도 화면으로 유지한다.
- 평소에는 Gold · 상점, 할로윈 기간에는 Gold · 사탕 · 상점으로 배치한다. 빈 사탕 자리나 중복 상점 버튼은 표시하지 않는다.
- 사탕은 기존 서버 `limited` 응답의 `season.active` 및 `tokens`를 사용한다. 클라이언트 날짜를 바꿔서 보상을 해금하지 않는다.
- 기존 일정: 한국 시간 2026-10-24 00:00 시작, 2026-11-15 00:00 종료(11월 14일 23:59까지).
- 접속/재접속, 파괴·구매 응답 및 30초 상태 갱신으로 표시한다. 시즌 시작 후 접속 중인 사용자는 다음 성공한 상태 조회(통상 30초 이내)에 표시된다. 네트워크가 끊기면 연결 복구 후 확인한다.
- 보유 사탕·한정 볼·일반 진행도에는 구조 변경이나 초기화가 없다. DB 마이그레이션은 필요 없다.
