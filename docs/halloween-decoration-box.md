# 할로윈 꾸미기 상자

상점 → 할로윈 상점에서 **100캔디로 상자 1개 열기**를 누릅니다. 1회 1개 확정 지급이며 일일 제한은 없습니다. 캔디만 사용합니다.

| 보상 | 확률 | 사용 |
|---|---|---|
| 길 잃은 꼬마 유령 | 1/3 | 장착하면 작은 유령이 볼 곁을 맴돕니다. |
| 잭오랜턴의 불씨 | 1/3 | 장착하면 타격 시 작은 호박불이 피어납니다. |
| 박쥐 무리 | 1/3 | 사용하면 가장자리로 박쥐가 잠깐 날아갑니다. 횟수 제한 없음. |

- 희귀도 구분 없이 같은 확률·같은 테두리·같은 재질과 색감의 SVG 일러스트를 사용합니다. SVG는 프로젝트에서 직접 작성했으며 외부 이미지 요청은 없습니다.
- 중복은 **할로윈 조각 1개**, 조각 **3개**로 원하는 미보유 꾸미기를 확정 교환합니다. 골드·능력치 효과는 없습니다.
- 보유 꾸미기와 조각은 환생·이벤트 종료 후에도 유지됩니다. 조각 교환과 장착/해제/사용은 판매 종료 후에도 가능합니다.
- 인벤토리 → 스킨에도 보관함이 표시됩니다. 유령·불씨는 동시에 하나만 장착합니다.
- 표시와 효과는 입력을 가로채지 않습니다. 파괴 시 유령·불씨는 정리되고 다음 볼 생성 시 복구합니다. 박쥐는 재사용해도 누적되지 않으며 최대 5초 후 제거됩니다. 작은 화면은 박쥐 수를 줄이고 동작 줄이기 설정은 반복 움직임을 없앱니다. 새 소리는 추가하지 않습니다.
- 계정 전환·페이지 숨김에서 효과와 타이머를 정리합니다.

서버는 기존 인증·점검·이용 제한을 거친 뒤 게임 진행 → 캔디 → 꾸미기 순서로 행을 잠급니다. 가격과 동등 확률 추첨은 서버가 결정하며, 요청 ID와 두 리비전으로 중복 차감·다른 탭의 오래된 요청을 막습니다. 재요청은 현재 잔액과 원래 추첨 결과를 반환합니다. 서버 RNG는 `floor(random()*3)`로 동일한 세 구간을 사용합니다. 클라이언트의 가격·확률·보상·타인 ID는 지급 기준으로 사용하지 않습니다.

두 새 테이블과 내부 스냅샷 함수는 직접 접근을 차단하고 RLS를 켭니다. 기존 일반 아이템·영겁 스킨·잭오랜턴 스킨의 뽑기 풀과 조각을 공유하지 않습니다. 마이그레이션은 현재 API를 내부 함수로 보존한 뒤 새 액션만 처리합니다.

검증: `halloween-decor.test.mjs`의 실제 SQL 및 구간 경계·재요청 검사, 기존 할로윈 스킨 회귀 검사, `halloween-decor-browser.py`의 Edge 터치 에뮬레이션(320×640, 844×390, 390×844 동작 줄이기, 1200×900). 실기기 검사는 아닙니다. 운영 확인은 `halloween-decor-production-check.sql`로 임시 계정의 변경을 모두 롤백합니다.

운영 마이그레이션: `20261022093644_halloween_decoration_box.sql`. 운영 SQL 검증도 통과했으며 모든 임시 데이터는 롤백했습니다. 보안 점검의 두 새 테이블 RLS 정책 없음(INFO)은 직접 접근을 막고 인증된 API 경로만 사용하는 의도된 설정입니다.
