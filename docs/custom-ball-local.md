# 커스텀 왁뿌볼 로컬 시안

사용자 요청에 따라 운영 배포·실제 결제·Supabase 변경 없이 먼저 검토하는 브랜치입니다.

## 실행

PowerShell에서 이 브랜치의 루트 기준:

```powershell
$env:WAKPPU_LOCAL_CUSTOM_PREVIEW='1'
$env:WAKPPU_LOCAL_PORT='4186'
$env:WAKPPU_LOCAL_SLEEP_TIME='2026-10-21T03:00:00Z'
node tools/local-server.mjs
```

`http://127.0.0.1:4186/?preview=custom`을 엽니다. 샘플 일반 계정으로 자동 로그인합니다. 관리자 계정·운영 API를 사용하지 않습니다. 전용 환경 변수와 쿼리 둘 다 있어야 편집창을 주입합니다. 운영 index.html에는 스크립트·스타일을 연결하지 않았습니다.

## 체험

- 30,000원: 구매 순간 선택한 볼 1종에 고정. 이미지 자유 교체.
- 50,000원: 모든 볼에 설정 가능. 볼별 저장 또는 전체 공통 설정. 단일 상품은 샘플 차액 20,000원으로 업그레이드.
- 모두 모의 이용권이며 돈을 받거나 실제 구매 권한을 지급하지 않습니다.
- PNG/JPG/WebP, 8MB 이하, 가로·세로 32~4096px. 파일은 브라우저에서만 읽으며 서버에 전송하지 않습니다. 확대·가로·세로 위치를 조절하고 512px WebP로 다시 인코딩하여 메타데이터 없이 저장합니다.
- 커스텀 설정과 변환 이미지는 이 origin의 IndexedDB에 로컬 계정별로 저장됩니다. 원본 이미지는 저장하지 않습니다. 미적용 편집은 닫으면 취소됩니다.
- 기존 볼 26종과 영겁 스킨 5종·호박 스킨 3종의 균열/파괴 프리셋, 별도의 사운드 세트를 선택합니다. 기본 볼 프리셋은 제공하고 미보유 스킨은 잠깁니다. `로컬 보유 스킨 샘플` 체크로 보유/미보유를 체험합니다.
- `이 볼로 인게임 플레이`는 샘플 계정의 해금/선택만 준비한 뒤 기존 타격 API로 플레이합니다. 기본 보상·필요 타격량·배율·재시도 처리는 기존 규칙을 사용합니다. 연출 설정을 바꾸는 것만으로 Gold를 지급하거나 타격 진행도를 초기화하지 않습니다.
- `마지막 타격 연습`은 일반 볼만 지원하며 기존 개발 테스트 모드로 마지막 한 번을 체험합니다. 저장/보상은 중지됩니다. 원래 볼은 커스텀 복원 버튼으로 복원하며, 전체 공통 설정의 개별 예외도 저장합니다.
- 원본 이미지가 들어간 SVG 내부를 기존 파편 `<use>`가 재사용합니다. 초월·화이트홀·관리자·할로윈 및 스킨 프리셋은 각각 기존 연출 엔진을 호출합니다. 별도 성능·보상 수치를 복사하지 않습니다.

## 검증

```powershell
python tools/custom-ball-browser.py
python tools/custom-ball-browser.py --effects
python tools/custom-ball-browser.py --special
node --test tools/admin-ball-event.test.mjs tools/input-guard.test.mjs tools/skins.test.mjs tools/skin-sounds.test.mjs tools/limited.test.mjs
```

브라우저 검증은 Edge 터치 에뮬레이션 320×640, 844×390, 1200×900, 390×844(모션 줄이기)입니다. 실물 기기 검증은 아닙니다. `--effects`는 프리셋 34종 전체를 마지막 타격으로 실행하고 연출 종료·이미지 재생성·보상 불변 및 미리듣기/음소거를 검증합니다. `--special`은 한정/관리자 볼의 실제 샘플 API 타격에서 정확한 보상 1회 지급을 검증합니다.

## 운영화 전에 필요한 작업

실제 가격/결제 상품 등록, 서버에서 확인한 단일/전체 이용권과 차액 업그레이드, 계정/보유 볼/보유 스킨 검증, 이미지 저장소의 비공개 정책·서버 이미지 디코딩/재인코딩·요청 제한, 기기 간 동기화와 삭제/복원 정책은 아직 연결하지 않았습니다. 이 시안의 클라이언트 샘플 구매·보유 체크를 운영 권한 검증으로 사용하면 안 됩니다. 현재 용도는 편집 UX와 인게임 외형·연출 검토입니다.
