# 영겁 전용 스킨 뽑기

## 운영 기능

- 상점 → 뽑기 아래 아이템/스킨 전환. 인벤토리 → 스킨에서 장착/해제·조각 교환.
- 스킨 뽑기는 1회만 제공. 1회 = 아이템 5회 가격 ×10 = 220,000,000,000,000,000,000G.
- 일반/희귀/영웅/전설/초월 확률 70/22/6/1.9/0.1%. 100번째 초월 확정, 아이템 천장과 별도.
- 중복 조각 1/3/10/30/100개. 미보유 스킨 교환 10/30/100/300/1,000개.
- 보유·장착·조각·천장은 서버에 저장되며 환생해도 유지. 장착은 영겁 해금 후 가능.
- 서버가 무작위 결과·차감·지급을 한 트랜잭션으로 처리. 요청 ID 재전송은 중복 차감하지 않음.
- 공통 item_revision으로 이전 Gold 저장의 차감 복구 방지. skin_revision으로 스킨 동시 변경 검증.
- 새 초월 획득 후 서버 지급 확인 → 전체 화면 컷신. 스킵/새로고침해도 서버 보유 유지.
- 서버 데이터만 장착 가능. 로컬 전용 샘플 지급·테스트 버튼은 운영 HTML에 주입되지 않음.
- 마이그레이션: `20261016092330_eternity_skins.sql`. 기존 모든 경제·이벤트 래퍼 뒤에 적용.
  신규 스킨 테이블 3개 모두 RLS 활성화/직접 권한 없음, 기존 내부 API 직접 호출 권한 회수.
  기존 status/rankings 공개 접근과 bootstrap의 점검/수면/제재 검증은 그대로 위임.

## 초월 획득 컷신 미리보기

상단 `초월 획득 컷신 미리보기` 버튼으로 전체 뷰포트 컷신을 실행한다.
약 5.2초: 어둠 → 두 문장 → 공간 균열 → 3.65초에 공/저음 등장 → 결과.
우주 배경/별자리/균열/궤도는 직접 작성한 SVG이며 외부 이미지는 사용하지 않는다.
효과음은 기존 Kenney CC0 legendary-late, transcendent-final MP3를 저음으로 재생한다.
건너뛰기/Escape는 결과로 이동하며, 결과의 확인/Escape로 닫는다.
장착하기는 로컬 샘플의 장착만 변경한다. Gold 차감·스킨 지급·뽑기는 발생하지 않는다.
중복 재생 방지, 키보드 포커스 가두기/복구, 배경 inert 복구, 타이머/음원 정리 적용.
동작 줄이기에서는 확대/충격파 없이 약 1.5초의 정적 전환과 낮은 효과음으로 표시한다.
운영용 신규 초월 획득에도 같은 컷신을 사용하며, 장착 버튼은 서버 장착 API를 호출한다.

`/?preview=skin-sounds`에서 5등급의 타격/균열/마지막 균열/파괴음을 비교한다.
선택 후 실제 영겁을 마지막 한 번 타격해 게임 파괴 연출과 함께 확인할 수 있다.
인벤토리에 아이템/스킨 버튼을 추가하고 스킨 5종 전체를 테스트용으로 제공한다.
장착/해제는 로컬 전용 키 wakppu-local-eternity-skin-v1에 저장된다.
은빛 무한 문양, 빙결 눈꽃, 불멸 불꽃, 시간 시계, 무한 궤도 문양의 SVG 외형이 적용된다.
균열·파편 색상은 스킨에 맞게 변경되며 파괴 속도·클릭 수·보상은 유지한다.
모든 로컬 테스트는 BGM을 생성/재생하지 않는다. 운영 BGM은 유지한다.
이 로컬 URL의 전체 스킨 샘플과 장착 저장은 운영의 실제 보유/장착과 구분된다.

## 등급별 움직임

- 일반: 은빛 무한 문양에 기존 영겁의 회전·맥동 움직임 복원. 기존 융합 파괴 연출 유지.
- 희귀: 정적인 얼음 재질, 타격 진행도별 눈꽃 균열, 바깥으로 흩어지는 얼음 조각.
- 영웅: 날개형 불사조 불꽃 문양과 다층 불꽃 그라디언트. 내부 불꽃 움직임, 타격 시 위로 날리는 불씨, 화염 분출.
- 전설: 시곗바늘 회전, 타격 시 시간 고리, 파편 정지 후 역회전/되감기.
- 초월: 공간 궤도 회전, 어두운 균열 틈에 보라색 후광/청백색 중심광을 겹쳐 내부 빛 표현.
  40% 미만은 희미한 빛, 이후 광량·폭·맥동 증가 및 최대 6개 빛 입자,
  95% 이후 입자가 중심으로 이동, 구체 수축 후 별빛 소멸.
  동작 줄이기에서는 맥동/입자 이동 없이 정적 빛만 유지. SVG 블러 없음.
  빛은 실제 균열의 d/pathLength/dashoffset/visibility를 공유한다.
  별도 균열 경로는 만들지 않으며 입자 시작점도 보이는 실제 균열 위에서 계산한다.
- 시간의 영겁 시침/분침: UTC+9 현재 한국 시간, 1초마다 갱신.
  분침은 초, 시침은 분/초까지 반영하고 인벤토리 썸네일에도 동일하게 표시한다.
  장식용 12초 회전 애니메이션은 제거했다.
- 미리보기의 균열 25/60/90% 버튼으로 단계별 차이를 바로 확인한다.

모든 스킨은 기존 영겁과 같은 2,100ms 연출(동작 줄이기 650ms),
62% 시점 보상 콜백, 이후 1,000ms 재등장 대기를 유지한다.
아이템 animation/respawn 배율은 각각 그대로 적용한다.
신규 파편은 모바일 16개/PC 24개(고리 최대 2개), 동작 줄이기 5개로 제한한다.
새 구체 생성/스킨 교체 시 타격 애니메이션 및 파괴 타이머를 취소한다.
전체 화면 흰색 플래시나 새 GPU 블러 효과는 사용하지 않는다.
그림 및 파괴 연출 스크립트의 캐시 버전을 함께 갱신해 기존 방문자의 색상만 표시되는 문제를 방지한다.
운영 서버와 연결하지 않고 테스트 모드로 저장/보상을 차단한다.

## 무료 음원 출처

- Kenney Impact Sounds: https://kenney.nl/assets/impact-sounds
- Kenney Sci-fi Sounds: https://kenney.nl/assets/sci-fi-sounds
- CC0-1.0, 상업 이용·가공 허용. 원본 라이선스는 sounds/eternity/에 보존.
- 개별 원본 파일명/해시/믹스 비율/길이/피크: sounds/eternity/sources.json

부드러운 타격을 공통 바탕으로 나무 파열, 유리 파편, 불꽃, 종, 저주파 공간음을 조합했다.
일반/희귀의 파괴는 0.85초, 전설/초월은 1.15초 이하. 기본 타격은 0.18초.
최대 피크 0.72 이하, 게임 재생 볼륨 0.65. 크기 대신 레이어로 등급을 구분한다.
모바일 Safari 호환을 위해 OGG 원본을 모노 MP3로 변환했다.
