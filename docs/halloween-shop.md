# 할로윈 상점과 점프스케어

상점의 **할로윈 상점** 탭에서 전용 스킨을 교환하고, 그 아래에서 **점프스케어 영구 해제**를
100캔디로 계정당 한 번 구매할 수 있습니다. 교환은 이벤트 기간 중에만 가능하며, 구매 효과는
환생·장착 스킨 변경·시즌 종료·재접속 이후에도 유지됩니다. 다시 켜는 기능은 없습니다.
스킨 장착·해제는 기존 인벤토리 → 스킨에서도 가능합니다.

해제 상품은 기본 잭오랜턴과 세 전용 스킨의 깜짝 전체화면 이미지와 전용 깜짝 음향만 차단합니다.
일반 파괴 연출·타격/파괴 효과음·골드/캔디 보상은 유지합니다. 구매 전 스킨 점프스케어는 기본과
같은 30% 확률이며 월식에는 붉은 그림자·달의 광륜과 낮은 음색을 적용합니다. 음소거 설정을 따릅니다.

서버는 한 트랜잭션에서 100캔디 차감, 영구 소유권, 아이템/스킨 revision, 재시도 응답을 저장합니다.
클라이언트의 가격·보유량을 신뢰하지 않습니다. `wakppu_limited_players.scare_disabled`는 브라우저에서
직접 수정할 수 없으며 기존 RLS와 API 권한·밴·점검·수면 시간 검사를 유지합니다.

검증: `node --test tools/pumpkin-skin-sql.test.mjs tools/pumpkin-skin-service.test.mjs tools/pumpkin-skins.test.mjs tools/jackolantern-scare.test.mjs`.
터치 세로/가로·데스크톱·효과 줄이기·음소거·실제 파괴 보상·영구 구매·재접속 검사는
`python tools/halloween-shop-browser.py <node.exe 경로>`로 수행합니다.
