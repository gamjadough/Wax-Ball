# 관리자 콘텐츠 자동 이용

인증된 비익명 관리자에게 일반 볼 전체 해금·발견과 인벤토리 아이템 전체 이용을 제공합니다. 기존 관리자 볼과 할로윈 볼의 상시 이용도 유지합니다.

- 일반 볼: 로그인 복원과 진행도 저장 시 `wakppu_item_balls`의 ID를 기존 해금·발견 기록에 합칩니다. 환생 후에도 전체 볼을 선택할 수 있습니다. 해금 기록은 영구 진행도이므로 관리자 역할이 나중에 해제돼도 기존 기록은 보존됩니다.
- 아이템: `wakppu_item_defs`의 모든 아이템을 관리자 인벤토리에 `∞`로 표시합니다. 사용 시 실제 구매·뽑기 수량은 변경하지 않습니다. 효과와 지속시간, 최대 연장 시간 및 요청 검증은 일반 사용자와 같습니다. 관리자 권한 해제 시에는 실제 보유량만 표시하고 사용합니다.
- 신규 아이템·일반 볼: 정식 서버 목록에 등록하면 다음 조회·로그인 복원부터 자동 반영됩니다. 데이터베이스에만 임의 ID를 추가하면 프런트엔드·기존 진행도 검증에 없는 콘텐츠를 플레이할 수 있는 것은 아닙니다.
- 스킨: 현재 독립된 스킨 소유·선택 시스템은 없습니다. 향후 추가 시 서버의 `wakppu_admin_content_access()`와 같은 공통 규칙에 연결하도록 프로젝트 지침에 명시했습니다.

`20261016083414_admin_content_access.sql`은 현재 운영 중인 모든 API 래퍼 뒤에 적용합니다. 기존 API를 먼저 호출하여 인증·밴·점검·수면 검증을 보존합니다. 아이템 사용 부분은 기존 트랜잭션 안에서 관리자 수량 검증·차감만 예외 처리합니다. 기존 랭킹·이벤트 API는 유지됩니다.

검증: `tools/admin-content.test.mjs`, `tools/admin-content-browser.py`에서 신규 목록 자동 반영, 반복 사용·재시도, 일반 사용자, 익명·권한 해제, 밴, PC·모바일 선택·환생을 확인합니다.
