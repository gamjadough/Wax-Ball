# 개발자 소장품

관리자 패널 상단의 **피어싱 조각 지급**을 누릅니다. 대상이 없으면 플레이어 검색으로 이동하고, 검색 결과에서 대상을 선택하면 지급 영역으로 이동합니다. 사유를 입력하여 **소장품 영구 지급**을 누릅니다. 이미 선택한 대상이 있으면 상단 바로가기가 지급 영역을 바로 엽니다.

- 이름: 누군가의 엉덩이 피어싱 조각
- 설명: 더럽다
- 능력치 효과 없음. 인벤토리에서 영구 보유하며 횟수 제한 없이 사용합니다. 사용하면 플레이 영역 구석에 이미지와 남은 시간을 10분 동안 표시합니다. 터치·클릭을 가로채지 않습니다.
- 다시 사용하면 그 시점부터 10분으로 갱신합니다. 같은 브라우저에서 새로고침해도 남은 시간이 유지되며, 로그아웃·다른 계정에서는 표시하지 않습니다. 접속하지 않아도 시간이 흐릅니다.
- 뽑기·상점·보상 배율에 포함되지 않습니다. 사용해도 골드, 아이템 효과, 천장, 수량, 진행 리비전이 변하지 않습니다.
- 서버에서 비익명 관리자 권한을 검사하며 지급과 감사 기록은 중복 요청에도 한 번만 생성됩니다.
- 지급받은 미플레이 빠른 시작 계정은 자동 삭제 대상에서 제외합니다. 본인이 확인 후 직접 삭제하는 기능은 계속 작동합니다.
- 이미지: 320px 투명 WebP, 약 16KB. [출처 및 생성 프롬프트](../wakppuball/images/items/README.md).

마이그레이션: `20261021131355_developer_keepsake.sql`. 기존 API 래퍼에 위임하며 지급 기록 테이블은 RLS 및 직접 접근 권한 차단으로 보호합니다.

검증: `keepsake-display.test.mjs`, `developer-keepsake.test.mjs`, `supporter-gold-sql.test.mjs`, `guest-exit-sql.test.mjs`, `developer-keepsake-browser.py` 및 `developer-keepsake-production-check.sql`.
브라우저 검사는 Edge 터치 에뮬레이션(320×640, 844×390, 390×844 동작 줄이기, 1200×900)이며 실기기 검사는 아닙니다.

운영 SQL 검증에서도 임시 계정 지급·중복 방지·반복 사용·빠른 시작 계정의 직접 삭제가 통과했습니다. 검증 데이터는 모두 롤백했습니다. 지급 기록 테이블의 RLS 정책 없음(INFO)은 직접 접근을 차단하고 검증된 API만 사용하는 의도된 설정입니다.
