# 현재 1등 전용 칭호 — 2026-10-25

인벤토리 → 프로필 → 칭호 선택에서 **👑 왁뿌볼의 정점**을 선택한다. 현재 공개 랭킹의 1등만 사용할 수 있으며 관리자도 순위 조건을 우회할 수 없다. 기존 자동 선택/후원 칭호를 임의로 교체하지 않는다.

공개 랭킹과 동일하게 환생 수 내림차순 → 정확한 Gold 내림차순 → 고유 ID 오름차순으로 판정한다. 숨김·이용 제한·미플레이 게스트 제외 조건도 동일하다. 과거 1위 기념 카드 보유 이력으로는 칭호 권한을 얻지 않는다.

순위가 내려가면 서버는 즉시 칭호를 공개하지 않고 재선택도 거절한다. 화면은 기존 랭킹 갱신(10초), 열린 프로필/인벤토리 갱신(15초)에 맞춰 반영한다. 선택 값은 보존하므로 다시 1등이 되면 기존 선택이 유효해진다. 칭호 없음으로 직접 해제할 수 있다.

Gold·재화·영구 배율·게임 보상은 변경하지 않는다. 금빛 글자와 은은한 광택만 적용하며 모션 줄이기에서는 광택 애니메이션을 끈다. 기존 영구 1위 기념 카드는 유지한다.

검증: 격리 SQL에서 실제 칭호 API, 1등 교체·동점·숨김·정지·만료·게스트 제외·위조 요청·접근 권한을 검사한다. 브라우저는 1200×900·320×640·844×390·390×844(모션 줄이기) 터치 에뮬레이션이며 실물 기기 검증은 아니다.
