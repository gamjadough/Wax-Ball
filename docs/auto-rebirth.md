# 자동 환생 영구 이용권

유료 상점의 `auto_rebirth` 상품은 4,000원이며 기존 계좌이체 주문·관리자 입금 확인·환불·직접 지급을 사용한다. 구매·재지급 후 OFF로 시작한다. 보유자는 유료 상점 또는 환생 창에서 ON/OFF를 변경한다. 비익명 관리자는 테스트용 접근이 가능하며 설정은 계정별로 저장한다.

ON일 때 화면이 보이고 게임이 준비된 동안 비용 도달을 검사한다. 파괴 연출, 보상, 진행 중 거래가 끝날 때까지 기다린다. 로그인하지 않았거나 숨겨진 탭·개발 테스트 모드·차단 상태에서는 실행하지 않는다. 자동 타격이나 오프라인 보상 기능은 없다.

서버는 기존 로그인·정지·점검·수면 시간 검사를 거쳐 이용권, 설정, 실제 골드, 환생 횟수, 아이템 revision을 확인한다. 기존 save/reset 체인으로 Gold·일반 해금·꿀·코팅·사용 중 아이템 효과를 초기화하고 한정 볼 선택을 해제한다. 망치·도감·보유 아이템·한정 볼 소유권은 보존한다. 환생 후 revision을 증가시켜 오래된 탭의 저장과 중복 환생을 막는다. 최대 1,000회에서는 실행하지 않는다. 환불·회수 후 설정은 OFF가 된다.

배포 순서는 `20261022083921_auto_rebirth.sql`과 `20261022085110_auto_rebirth_progress_reset.sql` 적용, `tools/auto-rebirth-production-check.sql` 롤백 검증, 게임 정적 파일 배포다. 후속 마이그레이션은 이전 형식과 아이템 형식의 타격 진행도를 모두 초기화한다. Edge Function 변경은 없다.

검증:

```powershell
node --test tools/auto-rebirth.test.mjs
python tools/auto-rebirth-browser.py
```

SQL 테스트는 1,000개 비용을 게임 데이터와 비교하고 OFF/부족/경계/버전/중복/최대/회수/재지급/정지/점검을 검사한다. 격리된 PGlite 구매 fixture는 기존 게임 저장 부분을 어댑터로 대체하며, 운영 롤백 검증은 실제 저장 체인을 검사한다. 모바일 브라우저 테스트는 320×640, 844×390 터치 에뮬레이션에서 주문·지급·보상 후 환생·설정 유지·계정 분리·환불·44px 조작·가로 넘침을 검사한다. 실물 기기 또는 실제 입금 검증은 아니다.

로컬 테스트는 기존 은행/커스텀 preview 플래그에 `WAKPPU_LOCAL_AUTO_REBIRTH=1`을 추가한다. 가짜 입금·로컬 계정에만 적용되며, 모든 테스트 파일과 비밀번호는 운영 화면에 포함되지 않는다.
