# 실험실 · 30초 균열 챌린지

기준 `f608993`의 로컬 실험실 사본에서 챌린지를 가져와 친구·공개 서버 공통 진입점에 연결했다. 로컬 전용 인증 조건과 동적 HTML 주입 대신 `crack-lab.js`/`crack-lab.css`를 정적으로 불러온다. 원래 테스트 사본은 수정하지 않는다.

- 실험실 바는 화면 전체 너비, 모서리 없는 직사각형이며 화면 아래에 붙는다. 안전 영역과 기존 메뉴를 위한 하단 스크롤 공간을 확보한다.
- 30초 동안 빛나는 균열을 누른다. 명중은 10점부터 콤보마다 2점씩 증가하고 최대 30점이다. 빗맞힘은 콤보만 초기화한다. 5콤보마다 파편을 강화한다.
- 기존 노란 볼 SVG와 전용 타격음을 재사용한다. 음소거·효과음 볼륨·모션 줄이기를 따른다. 파편 수와 동시 효과 수는 제한한다.
- 전체화면을 요청하고 거절되거나 지원하지 않으면 탭 전체 크기의 모달로 표시한다. 실험실이 요청한 전체화면만 닫을 때 종료한다.
- 최고 점수는 `wakppu-crack-lab:v1:best` 브라우저 저장소에만 기록한다. Gold·서버 계정·월간 랭킹에 보상을 추가하지 않으며 일반 볼의 균열 진행도를 수정하지 않는다.

검증: `tools/crack-lab-browser.py`가 격리된 로컬 계정으로 1200×900, 320×640, 844×390, 390×844(모션 줄이기)의 터치·하단 바·메뉴 공간·콤보·타격음 호출·시간 종료·기록 재접속·진행도 분리·키보드 반복 방지·ESC 종료를 확인한다. 별도 데스크톱 환경에서 실제 전체화면 API 진입/종료, HTML 오디오 재생 호출과 음소거를 검증한다. 브라우저 에뮬레이션이며 실물 기기의 주소창 숨김은 검증하지 않았다.
