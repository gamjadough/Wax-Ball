# 펫 세션 복원

같은 계정의 `TOKEN_REFRESHED` 이벤트에서 게임이 `wakppu-account-restored`를 중첩 발송한 뒤, 펫 UI의 인증 변경 리스너가 진행 중인 복원을 무효화하는 순서를 재현했다. 효과 렌더러도 모든 인증 이벤트마다 장착 캐시를 지웠고, 상점/보관함이 닫혀 있으면 다시 조회할 계기가 없었다.

동일 계정 세션 갱신에는 현재 펫과 캐시를 유지한다. 다른 계정/로그아웃 시에는 즉시 지운다. 인증 이벤트 리스너가 모두 끝난 다음 상태를 조회하도록 예약하며 동일 계정의 중복 요청은 하나로 합친다. 장착 변경은 진행 중인 이전 조회를 무효화해 오래된 선택으로 되돌아가지 않게 한다.

게임 상태 복원, pageshow, 화면 재표시, 온라인 복귀 시 상점 가시성과 무관하게 서버의 장착 정보를 읽는다. 일시적인 조회 실패는 1초부터 최대 30초 간격으로 재시도한다. 숨겨진 화면에서는 예약 재시도를 중지하고, 인증/권한 거부는 펫을 지운다. 차단 상태 변경도 렌더러에 전달한다. 펫 보유·장착 저장소·골드/시간 보너스·음소거·모션 줄이기 규칙은 변경하지 않는다. DB/Edge Function 변경은 없다.

`python tools/pet-restore-browser.py`는 상점/보관함을 열지 않고 실제 조회와 장착 API를 사용해 인증 이벤트 경합, 페이지 이동/뒤로가기, BFCache 복귀 이벤트, 통신 실패 후 재시도, 로컬 로그인 세션을 재주입한 닫힌 탭 복원, 계정 분리를 검사한다. Edge 320×640, 844×390(모션 줄이기), WebKit 390×844 터치 에뮬레이션이며 실물 기기 테스트는 아니다. 로컬 인증 fixture는 sessionStorage를 사용하므로 새 탭에 테스트 로그인 세션만 재주입하며, 펫 보유/장착 상태는 서버에서 다시 읽는다.
