# 입력 패턴 감지

2026-10-20: 최신 main의 후원자 골드 보너스를 통합했습니다. 서버·PGlite 회귀 테스트 29개와 터치 브라우저 검증 후 운영 DB·웹에 배포합니다. 운영 SQL 검증은 트랜잭션을 롤백하여 계정 보상·제재를 보존합니다.

## 입력·판정

- 공의 실제 포인터 입력 시각과 공 안의 상대 좌표(0~1000)를 모읍니다. 화면 절대 좌표·이메일·기기 지문은 수집하지 않습니다. 계정 전환·백그라운드 전환 때 버퍼를 초기화하고 관리자 개발 테스트 입력은 제외합니다.
- 15초마다 최대 512개의 새 입력을 전송합니다. 같은 보고의 재시도는 같은 UUID를 사용합니다. 서버는 입력 수·좌표 범위·정렬·보고 간격·세션의 중복 구간을 검증합니다. 원본 좌표를 DB에 저장하지 않고 요약만 기록합니다.
- 120개 이상, 10~30초 구간에서 초당 10회 이상이며 입력 간격 변동계수가 2% 이하이고 최대·최소 간격 차이가 4ms 이하일 때 복수 신호 후보가 됩니다. 같은 상대 좌표 구간 반복이 95% 이상이면 보조 이유와 가산점이 붙습니다. 좌표 하나만으로는 제한하지 않습니다.
- 해당 계정의 최근 실제 서버 타격이 8건 이상이고 서버 관찰 시간이 10초 이상이어야 점수가 쌓입니다. 한 번 분석한 서버 타격 기록은 다시 증거로 쓰지 않습니다. 망치의 피해량·파괴 횟수가 아닌 실제 새 타격 요청만 셉니다.
- 같은 입력 세션의 독립된 보고가 세 번 연속 조건을 충족하고 점수가 100이면 **2분 일시 제한**합니다. 영구 밴은 만들지 않습니다. 정상 보고에서는 점수가 줄고 연속 횟수가 초기화됩니다. 관리자 계정은 기록만 남기고 자동 제한하지 않습니다.
- 서버 타격 API에는 초당 40개 보충·최대 80개 버스트의 토큰 버킷을 적용합니다. 성공한 새 요청만 예산을 차감하며 중복 요청은 제외합니다. 초과 시 HTTP 429로 추가 타격을 거절하고 보상·진행도는 늘리지 않습니다. 속도 제한 하나만으로 밴하지 않습니다.

로그인 후 일반·한정·이벤트 타격은 서버 API를 사용합니다. 클라이언트에서의 숫자 증가를 타격 요청 수로 오인하지 않습니다. 입력 보고가 없거나 시각·좌표를 위조한 클라이언트까지 완벽히 판별하는 방식은 아니며, 기존 진행도 저장 API 전체의 경제값 검증을 대체하지 않습니다. 현 기준은 보수적 시작값으로 실제 운영 기록을 보고 조정해야 합니다.

## 관리자·저장

관리자 패널 아래의 ‘입력 패턴 감지 기록’에서 닉네임·의심 점수·이유·서버 타격 수·한국 시간 감지 시각·제한 종료 시각을 확인합니다. 20개씩 페이지를 나누며, 기존 사용자 선택·정지 해제로 제한과 누적 점수를 해제할 수 있습니다. 일반 계정이나 익명 관리자 세션은 조회할 수 없습니다.

새 테이블은 RLS를 켜고 직접 접근을 차단합니다. 요약은 계정당 최근 200건으로 제한합니다. 보고 처리 시 7일 지난 요약을 최대 500건씩 정리합니다. 중복 방지 보고 응답은 계정당 최근 64건을 보관합니다. 입력 시각 배열은 최근 서버 타격 확인에 필요한 최대 512건만 유지합니다.

`20261020085313_input_guard.sql`은 **현재 사용 중인 모든 기존 API 래퍼 뒤에** 적용합니다. 내부 함수·기존 API 직접 호출 권한은 제거하고 기존 인증·점검·수면·제재 검증을 재사용합니다. 운영에는 아직 적용하지 않습니다.

## 로컬 테스트

`WAKPPU_LOCAL_INPUT_GUARD_PREVIEW=1`과 낮 시간 테스트 시계를 설정해 `tools/local-server.mjs`를 실행하고 `/?preview=inputguard`에 접속합니다. 127.0.0.1에만 바인딩하며 운영 계정과 연결되지 않습니다. 해당 옵션을 켠 로컬 서버만 `/local/input-guard-demo`를 허용합니다.

미리보기의 불규칙 터치·같은 위치의 느린 터치·복수 신호 3회·속도 제한 버튼은 **합성 입력과 테스트 시간**으로 시나리오를 재현합니다. 관리자 기록 보기 버튼으로 샘플 관리자 화면에 들어갈 수 있습니다. ‘샘플 제한 해제’로 일반 샘플 계정으로 돌아옵니다.

검증 파일: `tools/input-guard.test.mjs`, `tools/input-guard-sql.test.mjs`, `tools/input-guard-browser.py`. 브라우저 검증은 터치 지원 320×640, 390×844, 844×390, 1200×900 에뮬레이션이며 물리 기기 테스트가 아닙니다.
