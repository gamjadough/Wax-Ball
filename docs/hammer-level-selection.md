# 망치 사용 레벨 선택

상점의 망치 업그레이드 바로 옆에서 사용할 레벨을 선택합니다. 구매한 최고 레벨과 사용 레벨을 분리하여 낮은 레벨을 선택해도 다음 업그레이드 가격·구매 기록이 유지됩니다. 선택 자체에는 Gold가 들지 않습니다.

- 기본값 `자동 · 최고 Lv.N`: 구매한 최고 레벨을 사용하고 업그레이드하면 새 레벨로 자동 전환합니다.
- `Lv.0 · 맨손`: 망치 기본 타격량 대신 1타격을 적용합니다. 아이템 효과는 기존 규칙대로 적용되며 구매한 최고 레벨은 유지됩니다.
- `Lv.1`부터 보유 최고 레벨까지 수동 선택: 업그레이드 후에도 선택한 사용 레벨을 유지합니다.
- 망치를 구매하지 않았거나 테스트 모드·타격/아이템 작업 중이면 선택할 수 없습니다. 모바일에서도 업그레이드와 같은 줄에 표시합니다.
- 선택은 `hammer_select` 서버 API로 저장합니다. 구매 범위, 요청 UUID, 아이템 revision을 검증하고 기존 요청 캐시로 중복 실행을 방지합니다. 일반 진행도 저장으로 선택 값을 덮어쓰지 않습니다.
- `hammer_selected_level`이 null이면 자동입니다. 일반·한정·이벤트 볼의 서버 타격 계산은 모두 이 값을 적용합니다. 기존 효과 배율과 구매한 최고 레벨은 유지합니다.

`20261016090507_hammer_level_selection.sql`을 기존 API 마이그레이션 뒤에 적용해야 합니다. 인증·밴·점검·수면 검증은 기존 API를 재사용합니다.

검증: `tools/hammer-selection.test.mjs`, `tools/hammer-selection-browser.py`, 기존 `tools/hammer-level.test.mjs`, `tools/hammer-browser.py` 및 관련 아이템·한정 볼·관리자 회귀 테스트.

Lv.0 사용은 `20261016091945_hammer_level_zero.sql`을 기존 망치 선택 마이그레이션 뒤에 적용합니다. 0은 맨손, null은 자동 최고 레벨이므로 별도로 취급합니다.
