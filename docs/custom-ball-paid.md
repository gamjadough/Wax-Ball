# 커스텀 왁뿌볼 유료 상점

기존 `custom-ball-local.md`는 초기 로컬 시안 기록이다. 이번 구현은 실제 계정·주문·서버 권한·비공개 이미지 저장에 연결한다.

## 구매와 사용

- 유료 상점에서 단일 볼 9,900원, 전체 볼 29,000원 상품을 구매한다. 기존 무통장 입금 주문과 관리자 확인 절차를 사용한다.
- 단일 상품은 주문할 때 선택한 보유 볼에 고정된다. 전체 상품으로의 차액 업그레이드는 19,100원이다. 기본 구매가 환불되면 미승인 업그레이드 주문으로 권한을 받을 수 없다.
- 가격 변경은 새 주문에만 적용한다. 변경 전 생성된 주문은 원래 금액·입금 확인·환불 기준을 유지하며, 기존 이용권·이미지·설정은 변경하지 않는다. 기존 미완료 주문으로 새 가격을 이용하려면 취소 후 재주문한다.
- 유료 상점 및 보유 상품에서 편집창을 연다. 전체 이용권은 볼별 설정 또는 전체 공통 설정을 지원한다. 이후 해금한 볼에도 공통 설정이 적용된다.
- 이미지는 자유 교체하며 균열·파괴와 소리를 각각 선택한다. 스킨 프리셋은 실제 소유권을 확인한다. 비익명 관리자는 전체 이용권과 프리셋을 자동 사용할 수 있다.
- 외형 설정은 보상·타격량·골드·선택된 볼의 진행도를 변경하지 않는다. 환불·권한 변경·계정 전환 시 허용되지 않는 이미지를 제거한다.

## 서버

`20261021131641_custom_ball_studio.sql`과 `custom-ball-image` Edge Function을 게임 화면보다 먼저 배포해야 한다. 함수는 JWT 검증을 켜고 기본 Supabase 서버 환경 변수를 사용한다. 서비스 키는 클라이언트에 전달하지 않는다.

가격 변경은 `20261023083506_custom_ball_prices.sql`을 추가 적용한다. 기존 API 래퍼의 신규 주문·카탈로그 가격만 수정하고 후속 기능·권한·주문 영수증은 보존한다. `tools/custom-prices-production-check.sql`로 새 단일·전체·차액 주문을 롤백 검증한다.

이미지는 512×512 RGBA PNG로 디코딩·재인코딩하고 메타데이터를 제거한다. 크기·압축 해제량·권한·요청 빈도·계정 총용량을 제한한다. 비공개 버킷의 경로는 서버가 생성하고 서명 URL은 15분 후 만료된다. 교체·복원·계정 삭제 후 파일은 서버 삭제 큐에서 정리한다.

저장 요청 UUID와 설정 revision으로 중복 저장과 오래된 편집의 덮어쓰기를 방지한다. 업그레이드 권한이 유효한 동안 원래 단일 상품의 환불은 관리자에게 차단 이유를 표시한다.

## 검증

```powershell
node --test tools/custom-ball-sql.test.mjs tools/custom-image.test.mjs
python tools/custom-paid-browser.py
deno check --config supabase/functions/custom-ball-image/deno.json supabase/functions/custom-ball-image/index.ts
```

SQL 테스트에는 기존 PGlite 테스트 런타임을 지정하는 `WAKPPU_TEST_NODE_PACKAGE`가 필요하다. 브라우저 테스트는 기존 Python 테스트 의존성을 사용한다.

브라우저 테스트는 실제 핸들러·PNG 코덱·마이그레이션을 로컬 PGlite와 메모리 파일 저장소로 실행한다. 유료 상점 주문, 관리자 지급, 이미지 저장·재접속, 실제 샘플 타격 보상, 차액 업그레이드, 계정 전환, 환불과 복원을 검사한다. 320×640, 844×390, 1200×900, 390×844(모션 줄이기) 터치 브라우저 에뮬레이션이며 실물 기기·실제 입금 검증은 아니다.

`custom-production-check.sql`은 배포 후 운영 DB에서 실행하는 롤백 검증이다. 테스트 설정 변경은 보존하지 않는다. 배포 완료는 마이그레이션 적용, Edge health의 PNG·비공개 버킷 검사, Pages 배포까지 확인한 후 보고한다.

로컬 유료 상점 검증 서버는 `WAKPPU_LOCAL_PAYMENTS=1`, `WAKPPU_LOCAL_BANK_PREVIEW=1`, `WAKPPU_LOCAL_CUSTOM_LIVE=1`을 함께 지정한다. 수면 시간과 별개로 로컬 테스트가 가능하도록 `WAKPPU_LOCAL_SLEEP_TIME=2026-10-21T03:00:00Z`를 지정할 수 있다. 이 설정은 운영 서버의 수면 시간에 영향을 주지 않는다.
