# 왁뿌볼 입력 누적 수정 — 2026-10-24

서버 응답을 기다리는 중 받아 둔 터치를 파괴 후에도 보존하여 다음 왁뿌볼에 적용하던 동작을 수정한다.

- 같은 왁뿌볼을 타격하는 동안에는 연속 입력 대기열을 유지한다.
- 마지막 타격으로 파괴를 시작할 때 남은 입력을 비운다.
- 모든 재생성 경로에서도 이전 입력을 비우며 자동으로 대기열을 재개하지 않는다.
- 파괴 연출 중 입력은 기존처럼 무시하고, 새 왁뿌볼이 등장한 이후 새로 누른 입력만 받는다.
- 보상·망치·펫·아이템 배율·파괴 연출 시간·동일 요청 ID 재시도 규칙은 변경하지 않는다.

검증: Node 회귀 테스트와 `tools/hit-queue-browser.py`의 320×640·844×390·1200×900 터치/마우스 브라우저 에뮬레이션. 300ms 지연하에 12번 연속 입력해도 5타짜리 왁뿌볼 한 개만 깨지며, 다음 왁뿌볼은 0타로 유지되고 새 입력에 정상 반응해야 한다. 실물 모바일 기기 검증은 아니다. 서버 스키마 변경은 없다.
