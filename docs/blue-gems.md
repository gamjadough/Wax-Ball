# 푸른젬 — 2026-10-25

- 사탕 오른쪽 푸른젬 버튼으로 전용 상점을 연다. 사탕 이벤트가 끝나도 푸른젬은 표시한다.
- 현재 일반·한정·관리자 이벤트 볼은 서버가 파괴를 확인할 때마다 1개 확정 지급한다. 타격마다 주지 않으며 요청 재전송은 중복 지급하지 않는다.
- 푸른젬과 영구 강화는 환생과 독립적인 계정별 테이블에 저장한다. 과거 파괴 기록에 소급 지급하지 않고 적용 이후부터 적립한다.
- 가격/영구 Gold 배율: 1K/×2, 10K/×5, 100K/×10, 1M/×100, 10M/×1K, 1Qa/×1M, 1Dd(10^39)/×1B.
- 각 상품은 표시 가격 전액으로 구매하며 순서 제한은 없다. 보유 중 가장 높은 단계 하나만 기존 최종 Gold 보상에 곱한다. 기존 푸른젬 지급량은 배율의 영향을 받지 않는다.
- 비익명 실제 관리자는 공용 서버 권한 검사로 모든 상품을 무료 적용할 수 있다. 별도 관리자 단계만 기록하며 실제 젬/구매 단계는 보존한다. 관리자 권한이 없어지거나 익명 세션이면 실제 구매 단계만 적용한다.
- 추후 푸른젬 구매 볼을 추가할 때 `wakppu_blue_gem_exclusions`에 ID를 등록해 기본 +1 드롭을 끄고 별도 규칙을 연결한다.
- Gold·기존 진행도는 일괄 마이그레이션하지 않는다. 신규 행 기본값은 0젬/×1이다.

검증: `tools/blue-gems.test.mjs`, `tools/blue-gems-browser.py`, 전체 Node 회귀 검사 및 운영 롤백 검사. 브라우저는 1200×900·320×640·844×390·390×844(모션 줄이기) 터치 에뮬레이션이며 실물 기기 테스트가 아니다.
