# 푸른 수정 왁뿌볼

- 도감 → 푸른젬 도감 → 푸른 수정 왁뿌볼에서 푸른젬 5,000개로 영구 해금합니다.
- 기본 균열 100, 현재 선택한 망치를 적용합니다. 파괴 시 푸른젬 5개를 지급하며 Gold는 지급하지 않습니다.
- 일반 볼의 푸른젬 1개 드롭과 중복하지 않으며, Gold 배율은 젬 보상에 적용되지 않습니다.
- 영겁 기본 파괴 연출과 같은 2.1초 연출 + 1초 재생성 대기입니다. 동작 줄이기는 0.65초 + 1초이며 기존 아이템·펫의 속도 효과를 동일하게 적용합니다.
- 푸른 수정 파편·고리 연출, 전용 SVG 외형, 직접 합성한 CC0 네 단계 효과음을 사용합니다. 기존 음소거·음량 설정을 따릅니다.
- 해금·선택·균열과 잔액은 서버에서 저장합니다. 환생은 소유권을 유지하며 균열만 초기화합니다.
- 실제 비익명 관리자는 공통 서버 권한 검증으로 구매 없이 선택할 수 있습니다. 관리자 체험이 실제 소유권이나 젬 잔액을 변경하지 않습니다.
- 기존 item_hit/입력 보호/펫 자동 공격 경로를 사용합니다. 요청 재전송은 구매·보상을 중복하지 않으며 수정 데이터 테이블과 헬퍼는 클라이언트에 비공개입니다.

검증: `tools/gem-ball.test.mjs`, `tools/gem-ball-browser.py`, 운영 DB 롤백 검증 `tools/gem-ball-production-check.sql`.
