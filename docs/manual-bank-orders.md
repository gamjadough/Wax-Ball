# 수동 계좌이체 유료 상점

기존 상점의 **아이템 구매 / 뽑기 / 유료 상점** 탭으로 구성합니다.
응원팩 1,100원(칭호·닉네임 테두리), 별빛 오라 스킨 3,300원(모든 볼에 장착 가능한 외형)을 판매합니다.
공격력·Gold·환생·뽑기 확률을 변경하지 않습니다. 유료 스킨은 기존 영겁 전용 스킨과 별도로 오라를 적용합니다.

## 판매 시작

운영 DB 초기 설정은 **주문 받기 꺼짐 / 계좌 미설정**입니다.
관리자로 로그인 → 관리자 패널 → **유료 상점 · 계좌이체 주문**에서 은행명, 받을 계좌번호,
예금주, 문의 방법을 입력하고 계좌를 직접 확인한 뒤 **새 계좌이체 주문 받기**를 켜세요.
은행과 연결하거나 계좌 소유자를 자동 검증하는 기능은 없습니다. 설정한 계좌가 구매자에게 안내됩니다.

구매자는 이메일을 연결·인증한 계정으로 입금자명과 상품을 선택합니다. 서버가 금액을 결정하고
주문 당시 계좌 정보를 주문에 고정합니다. 계좌를 바꿔도 기존 주문의 계좌는 바뀌지 않습니다.
판매 중지는 새 주문만 차단합니다. 기존 주문의 입금 내역도 계속 확인해야 합니다.

## 입금 확인과 지급

1. 구매자가 주문 내역의 계좌로 이체합니다.
2. **입금 알림 보내기**는 `claimed` 상태로 바꿀 뿐, 지급하지 않습니다.
3. 관리자가 은행의 실제 거래내역을 확인합니다. 입금자명만으로 판단하지 말고 금액·일시·거래번호를 함께 대조하세요.
4. 주문의 실제 입금액과 고유한 거래 식별 기록을 입력하고 **실제 입금 확인 · 상품 지급**을 누릅니다.
5. 서버가 주문·상품 지급·작업 기록을 한 트랜잭션으로 저장합니다. 동일 거래 기록을 다른 주문에 재사용할 수 없습니다.
6. 구매자는 새로고침하거나 유료 상점에서 지급 상태를 확인합니다. 승인된 스킨은 장착·해제할 수 있습니다.

구매자 본인은 자신의 주문만 조회·알림·입금 전 취소할 수 있습니다. 관리자만 전체 주문(50건씩), 계좌 설정, 지급·환불 완료 기록을 관리합니다.
사용자 인증 정보나 클라이언트의 역할·가격·소유권을 믿지 않습니다. 현재 DB 역할과 실제 이메일 인증 상태를 확인하고, 기존 밴·점검·수면 제한을 유지합니다.

## 취소와 환불

입금 전 `pending` 주문만 구매자가 취소할 수 있습니다. 입금 알림 이후에는 관리자에게 문의합니다.
취소 후 입금, 금액 불일치 등은 거래내역을 확인해 별도로 해결해야 합니다. 주문은 자동 만료하지 않습니다.
환불은 **관리자가 은행에서 먼저 실제 송금**한 다음, 완료 기록을 입력하고 **실제 환불 완료 · 상품 회수**를 누릅니다.
이 버튼은 돈을 보내지 않습니다. 지급된 상품만 회수하며, 별빛 스킨은 자동 해제됩니다.
상품과 주문은 환생·Gold 저장과 분리되어 유지됩니다. 구매 기록에는 플레이어 참조를 두어 임의 삭제를 막습니다.

## 로컬 체험

```powershell
$env:WAKPPU_LOCAL_BANK_PREVIEW='1'
$env:WAKPPU_LOCAL_PAYMENTS='1'
$env:WAKPPU_LOCAL_PORT='4196'
node tools/local-server.mjs
```

`http://127.0.0.1:4196/?preview=bank`

PGlite 테스트 의존성이 필요합니다. `tools/manual-bank-fixture.mjs`는 운영 SQL을 격리된 메모리 DB에 적용합니다.
샘플 은행·계좌는 로컬 어댑터에서만 켜며 실제 입금하면 안 됩니다. 서버 재시작 시 샘플 주문은 초기화됩니다.
유료 상점 맨 아래 로컬 체험 메뉴에서 구매자·관리자 계정을 전환할 수 있습니다.
운영 마이그레이션은 샘플 계좌나 주문을 생성하지 않습니다. 주문·계좌·지급 테이블은 RLS와 권한 회수로 직접 API 접근을 차단합니다.

## 검증

`node --test tools/manual-bank.test.mjs`는 실제 SQL로 기본 판매 중지, 권한, 계좌 스냅샷,
금액 검증, 타인 주문 차단, 알림 미지급, 중복 거래·지급 방지, 환불 회수, 마이그레이션 재실행,
환생 보존, 밴·점검, RLS를 확인합니다.
`python tools/manual-bank-browser.py <node.exe 경로>`는 모바일 세로·가로·효과 줄이기와 데스크톱에서
실제 상점 탭 이동·주문·관리자 지급·스킨 장착·재접속·환불을 검사합니다.
기존 `tools/shop-tabs-browser.py`로 구매·뽑기·연출 유지도 확인합니다.
